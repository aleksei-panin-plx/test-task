# CardForge

CardForge делает коллекции игровых карточек-предметов в стиле игры: коллекция — 16 сетов по 10 карт на одну
тему («Лето», «Кино», «Путешествие»). Гейм-дизайнер работает в своём агенте (Claude Code или Codex): называет
тему коллекции и, если нужно, число сетов, правит план (G1), проверяет готовые сеты (G3) и получает PNG.
Картинки рисует GPT Image 2.5 через OpenRouter; стиль, рамку, надписи и обрезку проверяют судьи и локальные
проверки ядра. Версия 0.0.1.

## Что где лежит

| Папка | Для кого | Что внутри |
|---|---|---|
| [`cardforge/`](cardforge/) | гейм-дизайнер на своём компьютере | ядро CardForge, локальный плагин для Claude Code и Codex (MCP по stdio), установщик одним действием (macOS: двойной щелчок по `installer/install.command`) |
| [`cardforge-lite/`](cardforge-lite/) | гейм-дизайнер, которому нужен только план | Light-версия локального плагина: только Gate 1 — план коллекции и таблицы контента по сетам (Markdown, CSV, JSON), без рендера, данных, весов и ключей; установщик одним действием (`installer/install.command`), команда `/cardforge-lite:new` |
| [`cardforge-server/`](cardforge-server/) | администратор сервера | сервер: MCP по Streamable HTTP с теми же 18 инструментами, очередь прогонов, личные ключи, страницы гейтов в браузере, месячный лимит на пользователя, учёт использования, хранение прогонов |

Обе папки **автономны**: в каждой своя полная копия ядра (`src/cardforge/`, `knowledge/`, `policies/`,
`prompts/`, `config/`, общие тесты `tests/`), ни одна не зависит от другой как от пакета. Копии одинаковы,
кроме намеренных расхождений из [`cardforge-server/core-sync.toml`](cardforge-server/core-sync.toml) (сервер
разрешает план от агента пользователя, рабочая папка `/srv/cardforge`). Правка ядра делается в папке 1 и
переносится на сервер только скриптом:

```bash
python -I cardforge-server/scripts/sync_core.py cardforge cardforge-server
```

Отчёт последней синхронизации с sha256 ядра — [`cardforge-server/docs/core-sync.md`](cardforge-server/docs/core-sync.md).

## С чего начать

- **Гейм-дизайнеру** — склонируйте репозиторий (`git clone https://github.com/aleksei-panin-plx/test-task.git`;
  всё нужное, включая данные, уже в нём) и следуйте [установке](cardforge/README.md) ([English](cardforge/README.en.md)), затем
  [как пользоваться](cardforge/plugin/README.md). Первый тест после установки: `/cardforge:new коллекция Лето, 2 сета`.
- **Администратору сервера** — [README сервера](cardforge-server/README.md): запуск, Docker, веса, данные,
  ключи, лимит, хранение, учёт использования, синхронизация ядра.

## Данные и что не входит в репозиторий

Клона достаточно: ничего не нужно получать отдельно.

- **Архив данных** `cardforge-data-0.0.1.tar.gz` (≈ 630 МБ: референсы игры `dataset/`, картинки рамки,
  свидетельства ревью масок) лежит в [`cardforge/data-parts/`](cardforge/data-parts/) семью частями по 90 МБ
  (GitHub не принимает файлы больше 100 МБ) с файлом `.sha256`. Установщик папки 1 склеивает их и сверяет
  sha256 сам; для сервера команда склейки — в [README сервера](cardforge-server/README.md).
- **Веса моделей** (u2net ≈ 176 МБ, CSD ViT-L ≈ 2,3 ГБ) в git не лежат: установщик и `cardforge fetch-assets`
  скачивают их сами по `models/*/source.json` со сверкой sha256 (файл 2,3 ГБ больше лимита и git, и LFS).

| Не в репозитории | Почему | Откуда берётся |
|---|---|---|
| папка `cardforge/assets/` (полный архив + веса для установки без интернета) | дублирует `data-parts/`, веса слишком велики | собирается `scripts/build_dist.py --with-assets` для передачи папкой |
| веса моделей | размер | скачиваются установщиком |
| `runs/`, `.env`, `.venv`, кэши | локальное состояние и ключи | создаются при работе; ключ OpenRouter — только в окружении или `.env` |
| `*.private*`, `labels.private/` | приватные метки людей | не распространяются |

Ручная разметка в `knowledge/` (`human_review.jsonl`, `disagreements*`, `human_feedback_v1.json`, `reviews/`)
и локальные пути в коде и тестах опубликованы как есть, архив данных заказчика — частями в `data-parts/`; оба
решения — явные решения владельца репозитория (2026-11-10).
