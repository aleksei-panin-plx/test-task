# CardForge для гейм-дизайнера

[English](README.en.md)

CardForge делает коллекции карточек-предметов (16 сетов по 10 карт) в стиле игры. Вы говорите своему агенту —
Claude Code или Codex — тему коллекции, смотрите план, проверяете готовые сеты и получаете PNG.

## Установка

**Основной путь — двойной щелчок** по `installer/install.command` в папке `cardforge` (Windows:
`installer\install.bat`, не проверено). Всё нужное — архив данных и веса — уже лежит в папке `assets/`. Ключ
OpenRouter установщик спросит окном. Подробно (что нужно, как понять, что всё получилось, ошибки, переустановка,
удаление) — в `README.md` папки `cardforge`.

Установщик ставит ядро в `~/.cardforge/current` и сам подключает плагин ко всем найденным агентам (Claude Code,
Codex). После него **ничего вручную делать не нужно** — перезапустите агента; в Claude Code введите
`/cardforge:doctor`.

### Вручную — только если установщик не смог подключить плагин

Ядро уже стоит в `~/.cardforge/current` (его ставит установщик); подставляйте этот путь.

1. **Ключ** (если при установке нажали Enter без ключа):
   ```bash
   printf 'OPENROUTER_API_KEY=%s\n' 'ваш-ключ' > ~/.cardforge/.env
   ```
2. **Claude Code:**
   ```bash
   claude plugin marketplace add ~/.cardforge/current
   ```
   ```bash
   claude plugin install cardforge@cardforge
   ```
   Перезапустите Claude Code. Проверка: `/cardforge:doctor`.
3. **Codex:**
   ```bash
   codex plugin marketplace add ~/.cardforge/current
   ```
   ```bash
   codex plugin add cardforge@cardforge
   ```
   Перезапустите Codex. Слэш-команд `/cardforge:…` в Codex нет — просите словами: «проверь CardForge»,
   «сделай 2 сета коллекции Лето».
4. **Ядро не в `~/.cardforge/current`** (ставили с `--home`): добавьте в `~/.zshrc`
   `export CARDFORGE_HOME=<эта папка>/current`.

### Свой ключ OpenRouter

Ключ компании настраивать не нужно. Ключ **другого** аккаунта OpenRouter: в Guardrails
([openrouter.ai/settings/guardrails](https://openrouter.ai/settings/guardrails)) разрешите провайдера **OpenAI**, в
Privacy ([openrouter.ai/settings/privacy](https://openrouter.ai/settings/privacy)) — запросы **без ZDR**. Ключ того же
аккаунта или организации — проверьте только ограничения самого ключа. `/cardforge:doctor` проверит маршруты и
назовёт настройку, если что-то не так.

## Первый запуск

`/cardforge:new коллекция Лето, 2 сета` — короткий и недорогой первый тест (в Codex — просто «сделай 2 сета
коллекции «Лето»»). Всю коллекцию — без числа: `/cardforge:new коллекция Лето`.

Коллекция — 16 сетов по 10 карт на одну тему. Если тема коллекции из запроса не ясна (например, «Япония» —
японское кино или коллекция «Япония»?), агент спросит.

1. **План коллекции (G1).** Агент покажет темы всех 16 сетов и по каждому из сетов 1–15 — список предметных
   карт таблицей. Золотые карты (персонажи коллекции) здесь не придумываются, только отмечены места: в сетах
   1–6 их нет, дальше от 1 до 4. Сет 16 (гранд-сет, только золотые) — только тема. Правьте словами: «в сете 3
   вместо торта бокалы», «тему сета 5 замени на рыбалку». Когда нравится — «запускай».
2. **Генерация.** Все сеты плана рисуются сразу, одним прогоном, в фоне (вся коллекция — это 130 карт, около
   часа и больше). «Как дела?» — агент скажет, сколько готово. «Стоп» / «продолжи».
3. **Спорные карты** по ходу вас не дёргают: ядро само перерисовывает их, а если не вышло — кладёт лучшую
   попытку в набор с оранжевой пометкой «не подтверждена судьями».
4. **Проверка коллекции (G3).** Листы 5×2 по сетам (места золотых карт — жёлтые заглушки). По каждой
   помеченной карте: принять, «перерисуй: ручка короче» или заменить альтернативой из `alternatives.md`.
   Если что-то похоже на чужой бренд или персонажа, у карты будет комментарий. Вариантов на выбор нет. Хотите
   смотреть спорные карты по ходу — скажите агенту «с проверкой карт» (G2 для этого прогона).
5. **Выдача.** Агент назовёт папку `delivery/current/`: `index.html` с темами сетов, по каждому сету PNG
   430×480, лист 5×2, превью в рамке. Рядом «Не прошли отбор» (`screened_out.html`) и `alternatives.md`.

**Варианты набора — по запросу:** `/cardforge:new 3 варианта набора «Пикник» коллекции Лето` — нарисуются
основной вариант и альтернативы — сколько скажете (не назвали число — 3). Основной выбирают судьи; на проверке можно
сделать основным другой: «основным — v03».

**Перерисовать карту** в любой момент, и после выдачи: `/cardforge:redo сет 2, карта 4: без надписей`.
Перерисованную карту вы посмотрите сами, выдача пересоберётся (прежняя версия — в `delivery/v01/`).

## Типичный бриф

«Коллекция Лето, без надписей» или «4 набора коллекции Путешествие». Для Китая добавьте
«для Китая» — ядро заменит запрещённые на рынке предметы само.

## Что значат пометки

| Пометка | Что это |
|---|---|
| авто-пропуск | карту приняло ядро: стиль уверенно в норме, проверки чистые (зелёная рамка) |
| не подтверждена судьями | ядро не смогло подтвердить карту за 3 попытки и положило лучшую (оранжевая рамка) — решите на G3 |
| касается верхнего края | объект упирается в верх окна карточки |
| заходит под рамку | часть объекта уйдёт под звёзды или плашку |
| закончились попытки | ядро трижды не смогло исправить — решите вы |
| комментарий IP | что-то похоже на известный бренд, модель или персонажа |

## Где результаты

Папка прогона — в `runs/<id>/` папки ядра. Вам нужна `delivery/current/index.html`. Технический журнал
(`report.md`, `events.jsonl`) — для команды CardForge.

## Частые ошибки

| Что видите | Что сделать |
|---|---|
| «только планы» | нет ключа OpenRouter — шаг 1 ручной установки |
| `cardforge-mcp: core not found` | задайте `CARDFORGE_HOME` (шаг 4 ручной установки) |
| агент молчит долго | «как дела?» — генерация идёт в фоне; «продолжи», если остановлена |
| «неполные варианты» на выборе | в варианте есть карты на проверке — сначала решите их |

## Матрица доступности

| Что есть | Что доступно | Проверено |
|---|---|---|
| Claude Code, macOS, ключ OpenRouter | полный сценарий | тестами на FakeBackend; живой прогон через плагин — после теста чистого листа |
| Codex, macOS, ключ OpenRouter | полный сценарий | установка и запуск MCP-сервера проверены (`CODEX_HOME` во временной папке); разговор с агентом и рендер — нет |
| Любой агент без ключа | только планы наборов | тест `test_plan_only_without_render_key_never_renders` |
| Windows, ключ OpenRouter | полный сценарий (OCR — RapidOCR, проверки текста не откалиброваны) | не проверено |
| Нет агента | недоступно (веб-версия — позже) | — |
