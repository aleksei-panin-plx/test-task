# CardForge — установка

[English](README.en.md) · как пользоваться после установки — [plugin/README.md](plugin/README.md)

CardForge делает коллекции игровых карточек-предметов (16 сетов по 10 карт) в стиле игры. Работает внутри
Claude Code (или Codex) как плагин: вы называете тему коллекции (и, если нужно, сколько сетов), смотрите план,
проверяете готовые сеты и получаете PNG.

## Что нужно

| | |
|---|---|
| Система | macOS (Apple Silicon или Intel). Windows — см. внизу, **не проверено** |
| Агент | установлен Claude Code или Codex (можно оба; как программа Claude / Codex / ChatGPT или как команда) — установщик найдёт их сам |
| Интернет | нужен при установке: ≈ 1 ГБ зависимостей Python; в копии из git ещё ≈ 2,6 ГБ весов моделей (в папке от команды они уже лежат) |
| Диск | ≥ 6 ГБ свободно (папка установщика ≈ 3 ГБ, после установки в `~/.cardforge` ≈ 4,5 ГБ) |
| Время | 5–15 минут |
| Ключ OpenRouter | ключ компании — у команды CardForge (свой: openrouter.ai → Keys). Без ключа — только планы, без картинок |
| Права администратора | не нужны |

## Что у вас на руках

Одна папка **`cardforge`** (≈ 3 ГБ) от команды CardForge — в ней уже всё:

```
cardforge/
├── installer/install.command   ← на это нажать (macOS)
├── installer/install.bat       ← на это нажать (Windows, не проверено)
├── assets/                     ← архив данных и веса моделей, установщик найдёт их сам
└── …
```

В `assets/` лежат архив данных (референсы игры) и веса моделей. Переносите папку `cardforge` целиком.

**Если вы склонировали git-репозиторий**, ничего дополнительно получать не нужно: папки `assets/` в нём нет, зато
архив данных лежит в `data-parts/` частями по 90 МБ (ограничение GitHub на размер файла). Установщик сам склеит
их и сверит sha256, а веса моделей скачает и проверит по `models/*/source.json`. Двойной щелчок и команда — те же.

## Установка — двойной щелчок

1. Откройте папку `cardforge` в Finder, затем папку `installer`.
2. Дважды щёлкните **`install.command`**. Откроется окно Терминала — в нём ничего печатать не нужно, просто ждите.
3. Появится окно «Вставьте ключ OpenRouter» — вставьте ключ (⌘V) и нажмите OK. Нет ключа — «Без ключа»
   (будут только планы; ключ можно добавить потом, см. ниже).
4. В конце появится окно «CardForge установлен». Окно Терминала можно закрыть. **Закройте и снова откройте**
   Claude (и Codex, если он есть) — иначе приложение не увидит новый плагин.

**Если macOS не даёт открыть `install.command`** («не удаётся проверить разработчика»; так бывает, если папку
скачали из интернета или прислали через AirDrop): откройте **Системные настройки → Конфиденциальность и
безопасность**, внизу у сообщения про `install.command` нажмите **«Всё равно открыть»** и снова дважды щёлкните
файл. С флешки или файлового сервера компании обычно открывается сразу.

Что делает установщик сам:
1. проверяет систему, место на диске и какие агенты установлены (Claude Code, Codex);
2. ставит `uv` и Python 3.12, если их нет;
3. копирует CardForge в `~/.cardforge/versions/0.0.1` и делает ссылку `~/.cardforge/current`;
4. ставит зависимости строго по `uv.lock`;
5. берёт веса моделей из `assets/` и сверяет sha256 (если их нет — скачивает);
6. распаковывает архив данных из `assets/`;
7. спрашивает ключ OpenRouter (окном) и хранит его в `~/.cardforge/.env` — при обновлениях он не теряется;
8. подключает плагин ко всем найденным агентам;
9. запускает проверку `cardforge doctor`.

Папку `cardforge` после установки можно удалить: CardForge работает из `~/.cardforge/current`.

## Свой ключ OpenRouter

По умолчанию нужен ключ компании от команды CardForge — с ним ничего настраивать не нужно. Если вставляете ключ
**другого** аккаунта OpenRouter, в этом аккаунте должны быть включены две настройки (без них карточки не
рисуются):

| Настройка | Где | Что включить | Зачем |
|---|---|---|---|
| Guardrails (ограничители) | [openrouter.ai/settings/guardrails](https://openrouter.ai/settings/guardrails) — для аккаунта и для самого ключа, если у ключа свои ограничения | разрешить провайдера **OpenAI** | карточки рисует GPT Image 2.5 только у OpenAI |
| Privacy (приватность) | [openrouter.ai/settings/privacy](https://openrouter.ai/settings/privacy) | разрешить запросы к провайдерам **без ZDR** (Zero Data Retention) | у GPT Image нет эндпоинта с ZDR; остальные вызовы (Kimi, Nano Banana) CardForge сам закрепляет за провайдерами с ZDR и запретом сбора данных |

- Ключ **того же аккаунта или организации**, что ключ компании, повторно настраивать не нужно — проверьте только
  ограничения, заданные на сам ключ (лимит, разрешённые провайдеры).
- На счёте должны быть средства ([openrouter.ai/settings/credits](https://openrouter.ai/settings/credits)).
- Проверка: `cardforge doctor` (его запускает установщик, а в Claude — `/cardforge:doctor`) отправляет по одному
  крошечному запросу (≈ $0) на каждый нужный маршрут с теми же настройками, что у настоящей генерации, и называет
  настройку, которую надо поменять. Пока маршрут отклонён, режим не «полный», а «blocked».

## Как понять, что всё получилось

Главный признак — окно «CardForge установлен». В окне Терминала перед ним — отчёт `doctor`; успех выглядит так:

```
CardForge doctor: plugin mode full; no errors
[OK] python: Python 3.12…
[OK] disk: … GB free; required 6 GB
[OK] plugin_mode: full: GPT Image 2.5 via OpenRouter; Nano Banana only as the reserve
[OK] ocr: engine apple-vision
...
==> CardForge is installed in /Users/<вы>/.cardforge/current. Restart Claude Code and type /cardforge:doctor
```

- Главное — `no errors` в первой строке и `plugin mode full`.
- Последняя строка «development checks, not used by the plugin» — проверки разработчика, **на работу не влияют**.
- `plugin mode plan-only` — ключ не задан: будут только планы. Как добавить ключ — ниже.

Потом **перезапустите Claude Code** и введите `/cardforge:doctor`: агент скажет «полный режим».

## Первый запуск

| Что написать агенту | Что получится |
|---|---|
| `/cardforge:new коллекция Лето, 2 сета` | **первый тест — начните с него**: план коллекции (G1) с темами 16 сетов, рисуются только 2 сета по 10 карт |
| `/cardforge:new коллекция Лето` | вся коллекция: в плане 16 тем, рисуются сеты 1–15 (сет 16 — гранд-сет из золотых карт, только тема) |
| `/cardforge:new 3 варианта набора «Пикник» коллекции Лето` | варианты одного набора — только по запросу: основной (его выбирают судьи) + 3 альтернативы; число альтернатив — сколько скажете |

1. Если тема коллекции не ясна из запроса однозначно, агент спросит — темы «по умолчанию» нет.
2. **G1 — план коллекции**: темы сетов и по каждому сету список карт. Правьте словами («в сете 3 вместо торта
   бокалы»), затем «запускай».
3. Все сеты плана рисуются одним прогоном в фоне; спорные карты ядро перерисовывает само.
4. **G3 — проверка**: листы по сетам, помеченные карты — принять, перерисовать с правкой или заменить
   альтернативой. Затем агент назовёт папку выдачи с PNG.

Подробно — [plugin/README.md](plugin/README.md).

**Codex:** установщик подключает плагин сам, если Codex установлен. Перезапустите Codex и попросите словами
«проверь CardForge», затем «сделай 2 сета коллекции Лето» — слэш-команд `/cardforge:…` в Codex нет. Ручная установка плагина: `codex plugin marketplace add ~/.cardforge/current`, затем
`codex plugin add cardforge@cardforge`. Удаление: `codex plugin remove cardforge@cardforge` и
`codex plugin marketplace remove cardforge`.

## Если что-то пошло не так

Установщик показывает окно «CardForge не установлен: …» с причиной, а в окне Терминала остаётся полный текст.

| Что видите | Что сделать |
|---|---|
| «не найден ни Claude Code (claude), ни Codex (codex)» | установщик ищет и команды, и приложения (Claude, Codex, ChatGPT); если агент стоит, но не найден — откройте приложение один раз (оно докачает Claude Code), закройте и снова дважды щёлкните `install.command`; не помогло — пришлите текст окна Терминала |
| «нет архива данных…» | папка `assets/` неполная: попросите у команды CardForge папку целиком (копия из git: нет `data-parts/` — склонируйте репозиторий заново) |
| «архив данных из data-parts/ повреждён» | части скачались не полностью: склонируйте репозиторий заново (`git clone`, не «Download ZIP» с обрезанными файлами) |
| «папка CardForge неполная: нет …» | в папке не хватает файлов: скопируйте папку `cardforge` целиком или склонируйте репозиторий заново. Если папка лежит в iCloud Drive («Рабочий стол», «Документы»), перенесите её, например, в «Загрузки» |
| «не удалось полностью скопировать CardForge…» | то же (часто — iCloud Drive) или у Терминала нет доступа к папке: Системные настройки → Конфиденциальность и безопасность → Файлы и папки |
| `need 6 GB free disk` | освободите место |
| ошибка при скачивании или `sha256 … != …` | плохая сеть или повреждённый файл: запустите установку ещё раз |
| `doctor found errors` | в окне Терминала над этой строкой — строки `[ERROR]` с причиной; исправьте и запустите снова |
| `plugin mode plan-only` | ключ не задан — запустите установку ещё раз и вставьте ключ в окне |
| `plugin mode blocked`, `openrouter_route:… guardrails` | в Guardrails аккаунта или ключа не разрешён OpenAI — см. «Свой ключ OpenRouter» |
| `openrouter_route:… privacy` | в Privacy аккаунта не разрешены запросы без ZDR — см. «Свой ключ OpenRouter» |
| `openrouter_route:… key` / `credits` | ключ не принят или на счёте OpenRouter нет средств |
| `openrouter_route:… probe_model` (предупреждение) | проверка этого маршрута не настроена — на работу не влияет, сообщите команде CardForge |
| в Claude Code нет `/cardforge:…` | перезапустите Claude Code; если не помогло — запустите установку ещё раз |

Если не получается — выделите весь текст в окне Терминала (⌘A, ⌘C) и пришлите команде CardForge.

## Переустановка и обновление

Дважды щёлкните `installer/install.command` в новой папке `cardforge`. Ключ сохраняется; если ключ нужно
поменять — удалите файл `~/.cardforge/.env` и запустите установку снова.

## Удаление

Для удаления нужен Терминал (Программы → Утилиты → Терминал); выполните по очереди:

```bash
claude plugin uninstall cardforge@cardforge
```

```bash
claude plugin marketplace remove cardforge
```

```bash
rm -rf ~/.cardforge ~/.local/bin/cardforge-mcp
```

Если плагин стоял и в Codex: `codex plugin remove cardforge@cardforge`, затем `codex plugin marketplace remove cardforge`.

Последняя команда удаляет и готовые наборы в `~/.cardforge/current/runs/` — сохраните нужные заранее.

## Для опытных: установка из Терминала

`sh installer/install.sh` делает то же самое без окон. Параметры:

| Параметр | Что делает |
|---|---|
| `--data <архив>` | архив данных не из `assets/` |
| `--plugin auto` / `claude` / `codex` / `both` / `none` | куда ставить плагин; по умолчанию `auto` — во все найденные агенты |
| `--home <папка>` | вместо `~/.cardforge` |
| `--weights-from <папка models>` | веса не из `assets/models` (sha256 сверяется) |
| `--no-data` | ставить без архива (проверки стиля работать не будут) |
| `--dry-run` | только показать шаги |

Проверка установки в любой момент: `~/.cardforge/current/.venv/bin/cardforge doctor` (в Claude Code —
`/cardforge:doctor`). `--offline` — без проб маршрутов OpenRouter.

## Windows — не проверено

Установщик для Windows написан, но ни разу не запускался на Windows. Дважды щёлкните `installer\install.bat`
(архив и веса он тоже берёт из `assets\`). Если Windows предупредит о неизвестном издателе — «Подробнее» →
«Выполнить в любом случае».

На Windows проверка надписей идёт через RapidOCR и не откалибрована.
