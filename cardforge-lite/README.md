# CardForge Light — план коллекции и таблицы контента (Gate 1)

CardForge Light — облегчённая версия локального плагина CardForge для Claude Code и Codex. Она делает
**только Gate 1**: план коллекции игровых карточек-предметов и таблицы контента по сетам. Картинок не рисует.

Гейм-дизайнер называет тему коллекции и, если нужно, число сетов; агент (Claude Code или Codex) пишет план по
задачам ядра, ядро проверяет его по грамматике сетов, словарю фонов и политикам, при ошибках отправляет на
ремонт и собирает таблицы: в чат (Markdown) и в файлы CSV и JSON. Человек правит план словами или говорит «ок».

Версия 0.0.1 (ядро планировщика из папки 1 `cardforge/`, сборка 2026-11-13).

## Чем отличается от полной версии

| | Полная (`dist/cardforge/`) | Light (`dist/cardforge-lite/`) |
|---|---|---|
| Результат | PNG-карточки по сетам, листы 5×2, выдача | план коллекции и таблицы контента (Markdown, CSV, JSON) |
| Гейты | G1 план → рендер → G2 (по запросу) → G3 | только G1: план → правки → «ок» |
| Рендер, судьи, правки картинок, экспорт | есть (GPT Image 2.5 через OpenRouter, судьи, edit pass) | нет |
| Описание карточки | объект, категория, фон | + `main_object` (форма, пропорции, главный цвет) и `environment` (окружение, только категория 4) |
| Инструкция планировщика | строки в коде (`planner.py`) | файлы `prompts/planner/*.md` — правятся без кода |
| Ключ OpenRouter, леджер, маршруты | нужны для рендера и судей | **не нужны**: план пишет агент по своей подписке, платных вызовов нет |
| Данные и веса | архив референсов ≈ 630 МБ (`data-parts/`), веса ≈ 2,5 ГБ | нет: только размеченный каталог (`cards.jsonl`) для примеров |
| Зависимости | torch, transformers, opencv, rembg, OCR… | pydantic, typer, pyyaml (≈ 40 МБ с окружением) |
| Установка | 5–15 минут | 1–3 минуты |
| Имя плагина и команды | `cardforge`, `/cardforge:new` | `cardforge-lite`, `/cardforge-lite:new` |
| Папка установки | `~/.cardforge` | `~/.cardforge-lite` |

Обе версии можно поставить на одну машину: имена плагина, MCP-сервера, папки установки и переменных окружения
(`CARDFORGE_LITE_HOME`, `CARDFORGE_LITE_RUNS_DIR`) у Light свои.

Что сохранено из полной версии без изменений: план всех сетов за один проход, число сетов из запроса (1–16),
уточнение неоднозначной темы, золотые позиции (0×6, затем 1, 1, 2, 2, 2, 2, 3, 3, 4), сет 16 — только тема,
грамматика сета (категории 1–4, масштабы, типы, цвета фона), словарь мотивов и цветов, правило контраста
фона с объектом, язык материалов (`config/material_rules.toml`, `material_budget.toml`), политики
(`policies/ip/baseline.md`), ремонт плана до двух раундов,
правки человека дословно.

**Политики в Light строже.** `policies/ip/baseline.md` и **все** культурные пакеты из `policies/culture/`
(сейчас `china.md`) применяются к каждому плану всегда, без указания рынка; новый файл в этой папке
подхватывается сам. Любое правило стадии plan — ограничение при любой severity (block, review, advise):
объект, который ему противоречит, заменяется, замена пишется в `policy_notes` сета и показывается в
разделе «Политики» плана (какие пакеты применены, что на что заменено). В задание планировщику идут только
правила-ограничения, без подсказок «что приветствуется».

## Установка

Нужен Claude Code или Codex (приложение или командная строка) и интернет для первой установки (uv и Python 3.12).

- **macOS:** двойной щелчок по `installer/install.command`. Окно Терминала откроется само, печатать ничего не
  нужно; в конце — окно «CardForge Light установлен».
- Из терминала (macOS, Linux):

  ```bash
  sh installer/install.sh
  ```

  Параметры: `--plugin claude|codex|both|none`, `--home <папка>`, `--dry-run` (только показать шаги).
- **Windows** (не проверено на Windows): двойной щелчок по `installer/install.bat`.

Установщик копирует папку в `~/.cardforge-lite/versions/0.0.1` (ссылка `~/.cardforge-lite/current`), ставит
зависимости из `uv.lock`, подключает плагин `cardforge-lite` к найденным агентам и запускает `cardforge doctor`.
Повторный запуск чинит или обновляет установку. Ключей не спрашивает.

После установки перезапустите агента и проверьте: `/cardforge-lite:doctor` (в Codex — «проверь CardForge Light»).

## Как пользоваться

Пример запроса в Claude Code:

```text
/cardforge-lite:new коллекция Лето, 2 сета
```

В Codex или без команды — словами: «план коллекции Лето, 2 сета». Если тема неоднозначна («2 сета про
Японию»), агент сначала спросит: коллекция «Япония» или сеты про Японию внутри другой коллекции. Без числа
сетов планируется вся коллекция: 16 тем, карты в сетах 1–15, сет 16 — только тема.

Дальше:

- правка словами — «в сете 2 вместо зонта шезлонг», «тему сета 1 замени на рыбалку» (или
  `/cardforge-lite:edit …`): план уходит на ремонт с вашей правкой и показывается снова;
- «ок» / «утверждаю» — таблицы помечаются как утверждённые;
- `/cardforge-lite:status` — где сейчас план.

### Файлы результата

Каждый план — папка `~/.cardforge-lite/current/runs/<run_id>/`:

| Файл | Что внутри |
|---|---|
| `tables/plan.md` | то же, что в чате: темы сетов и таблицы по сетам |
| `tables/cards.csv` | одна строка на позицию: `set_index, set_theme, card_id, position, slot (object / gold / grand_set), object_name, main_object, category, environment, background_motif, background_color, surface, object_description, policy_flags, replaced` (что было на этом месте до замены по политике) |
| `tables/plan.json` | весь план: коллекция, темы, `policies` (пакеты и замены), конфликты брифа, предупреждения проверок, правки, все поля карт |
| `plan/`, `tasks/`, `events.jsonl` | раунды плана с ошибками, задачи ядра и ответы агента, журнал решений |

## Офлайн-проверка (без агента)

```bash
.venv/bin/cardforge plan "Лето" --sets 2 --fake --root .
```

`--fake` — детерминированный офлайн-планировщик (одинаковый набор реквизита киностудии): проверяет, что знания
читаются, проверки проходят и таблицы собираются. Качества плана он не показывает.

## Настройка знаний

Фоны (мотивы, цвета, контраст с объектом), категории 1–4 и детализация описания карточки правятся в файлах —
[docs/guides/customize-knowledge.md](docs/guides/customize-knowledge.md).

## Что проверено, что нет

| | Статус |
|---|---|
| тесты Light (`pytest`, без сети) и `ruff` | зелёные |
| dry-run на fake LLM: 2 сета и вся коллекция (16 сетов, золотые позиции, гранд-сет) → таблицы | проверено |
| MCP по stdio: `initialize`, инструменты, путь `start_plan → задачи → get_plan → approve_plan` | проверено в тестах |
| установщик macOS на чистой копии во временной папке (`uv sync --frozen`, `doctor`, лаунчер MCP) | проверено |
| установка плагина в живой Claude Code / Codex и план реальным агентом | не проверено |
| Windows (`install.bat` / `install.ps1`) | не проверено |
